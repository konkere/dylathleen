# Dylath-Leen

A harbor for Linux applications.

[English](README.md) · [История изменений](CHANGELOG.md)

Самостоятельный форк [bauh](https://github.com/vinifmor/bauh) автора Vinícius Moreira под лицензией [Zlib](LICENSE). В нативном интерфейсе PyQt5 доступны Flatpak, Snap, AppImage и Web Apps.

Соберите пакет командой `./packaging/build-deb`, затем выполните `sudo apt install ./dist/dylathleen_0.2.0-1_all.deb`. Запустите Dylath-Leen из меню или командой `dylathleen` от обычного пользователя. APT устанавливает сам менеджер и его зависимости. Для управления приложениями внутри программы он не используется.

Обновите список, выберите приложения и проверьте версии в окне подтверждения. Если Flatpak сообщает ту же версию и новый коммит, интерфейс покажет обновление сборки. Если метаданных недостаточно, целевая версия останется неизвестной. Источник версии — каталог соответствующего репозитория. Параметр `--offline` позволяет посмотреть локальный список, `--settings` открывает настройки, `dylathleen-tray` запускает значок в области уведомлений.

Для Snap нужен работающий snapd, для поиска Flatpak — настроенный репозиторий. Модуль AppImage рассчитан на x86-64. Для упаковки сайтов унаследованный модуль Web Apps загружает Nativefier/Node/Electron. Старые локальные приложения и настройки bauh автоматически не переносятся. Целевые платформы — Ubuntu 22.04/24.04/26.04 и Debian 12/13. [Подробности и ограничения](docs/iteration-1.md).
